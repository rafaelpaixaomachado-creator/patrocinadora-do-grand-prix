
# 🏎️ ENERGY F1 - Patrocinadora do Grand Prix

## 📌 Sobre o projeto

O ENERGY F1 é um projeto de desenvolvimento web inspirado no universo da Fórmula 1. 
O objetivo é apresentar informações sobre o automobilismo, equipes, pilotos e corridas, utilizando um design moderno e inspirado na velocidade das pistas.

## 🎯 Objetivo

Desenvolver um site com uma interface intuitiva e visual esportivo, destacando o universo da Fórmula 1 e a identidade visual da marca ENERGY F1.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3

## 🎨 Características do site

- Página inicial com banner principal.
- Menu de navegação.
- Seção de apresentação das equipes.
- Área dedicada aos pilotos.
- Seção sobre corridas.
- Layout responsivo.
- Design inspirado nas cores da Fórmula 1.
